# Multiverso Rick and Morty

Site estático que consome a [Rick and Morty API](https://rickandmortyapi.com/) com `fetch` e cria os cards dinamicamente com JavaScript (`createElement` + `appendChild`).

Tecnologias: HTML, CSS e JavaScript puros, sem frameworks.

Recursos: busca por nome, filtro por status, paginação, favoritos (salvos no navegador) e layout responsivo.

## Como rodar
Abra o `index.html` no navegador. Não precisa de token nem instalação.
